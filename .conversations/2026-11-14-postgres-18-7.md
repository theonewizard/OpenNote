- R-P8-032: the 9.9 run left one finding in all four images: `krb5-libs` 1.21.1-10.el9_8.1 (HIGH CVE-2026-107364), which the 9.9 base build of 2026-11-12 still carries; the fix 1.21.1-10.el9_9.2 is in the UBI repositories but in no base image build yet (Docker Hub's mirror lists none newer). A targeted upgrade rather than a blanket `microdnf upgrade`, to keep the change small and builds as reproducible as the unpinned UBI packages already allow.
